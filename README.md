# Flood/Inundation Raster Post-Processing Project

## Overview

This project contains tools and workflows to post-process coastal flood or storm surge inundation raster data. The processing pipeline includes:

1. **Clipping rasters** to administrative boundaries.
2. **Cleaning coastal inundation** to retain only regions connected to the coastline.
3. **Optional CSV and shapefile analysis** for reference points or metrics.

These scripts and notebooks are designed for reproducible analysis and reporting.
